# TaskFlow

A simple task manager web app built with a React frontend and a Node.js backend.

## Features

- User registration and login
- Token-based authentication
- Create, read, update, and delete tasks
- Persistent storage in `data/db.json`

## Run locally

```bash
node server.js
```

Then open `http://localhost:3000`.

## Notes

- The frontend uses React in the browser through CDN scripts.
- The backend uses only Node.js built-in modules, so no package installation is required.
